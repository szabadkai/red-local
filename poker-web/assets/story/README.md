# Story sprite sources

`traveler.png` is a byte-for-byte copy of `Assets/doc.png`.
`pumpkin.png` is a byte-for-byte copy of `Assets/pumpkin_dude.png`.
Both retain their original licensing terms and are covered by the repository's
asset rights notice. No new third-party artwork was downloaded for the story.

Supporting cast also uses the already bundled `assets/dungeon.png` atlas.
Large creature silhouettes and story props are drawn by `story-art.mjs` on the
same two-world-unit pixel grid as the game.
